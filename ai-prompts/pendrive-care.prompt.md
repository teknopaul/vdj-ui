# Pendrive care

Breaking pendrives is common with rekordbox use because of all the small writes, botht he PC app and the decks degrade pendrives.

We want to add some tools to help

- Can we detect pendrive chip makes?  
  - I know Sandisk and Kingston are pretty reliable, but others are not.
  - Users should be able to mark a device type as one they consider reliable.
  - for unreliable types (according to users preference) we should highlight the readback/verification options?
- Write caching in the Linux kernel is also good for small writes, I have good experience with it.
  - can we have some options to enable that on a pendrive that is plugged in before export?
  - can we have IU feed back on fllush state?
