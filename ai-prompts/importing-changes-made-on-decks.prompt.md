Often I partially create a playlist on the computer and them play it on real decks.

While playing it I often make adjustments to the beat grid and CUE points on the decks.

We can now read pendrives over the network, so it should be possible to copy back information changed on the deck to the computer version of the playlist in trakcrate.

To do this we need to match up a playlist on a deck with a playlist in the trackcrate database.

In the playlists view, the names will always match up if pendrives are always created via our own exports.

From that we nee dto work back to the Foldeer location in the "track-master-copy".

Since playlists may be slightly different (order and selection of tracks in the list) we should only import certain changes in the play list track by track and not fail if the track isn't is a particular playlist in trackcrate.

We don't want to import all the meta data only meta data that can be changed on the physical decks this is

- beat grid (decks can edit this)
- cue points (decks can edit this)
