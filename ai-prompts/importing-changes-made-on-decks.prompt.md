Often I partially create a playlist on the computer and them play it on real decks.

While playing it I often make adjustments to the beat grid and CUE points on the decks.

We can now read pendrives over the network so it should be possibel cto copy back information changed ont eh deck to the computer version of the play list.

To do this we need to match up a playlist on a deck with a playlist in the trackcrate database.

IN the playlists view, the names will alwyas match up becuses pendrives are always created via edports.

But  in trakcrate we can have a playlist int he play list view and in multiple `Virtual pendrives`  so when importing changes we should have the optio to import to play list and a selectablee list of `virtual Pendrives` in which the same playlist occurs.

Since playlists may be slightly different (order and selection of tracks in the list) we should only import certain changes in the play list track by track and not fail if the track isnt is a particualr playlist in trackcrate.

We dont want to import all the meta data only meta data that hcan be changed ont he physical decks this is

- beat grid
- cue points
- rating stars
